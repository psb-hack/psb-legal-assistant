# ADR 0001. Плоские модули ядра под ZIP-сабмит

- Статус: принято
- Дата: 2026-11-11
- Задача: [PSB-2](https://d12-team.atlassian.net/browse/PSB-2)

## Контекст

Платформа принимает архив без вложенных пакетов: в корень кладутся `solution.py`, `requirements.txt` и другие корневые `.py`. В репозитории нужна обычная структура (тесты, docs, scripts, web). Сборка должна превратить одно в другое без `sys.path` в ядре.

## Драйверы

1. Импорты на платформе — только соседние модули в корне рабочей директории.
2. Ядро не зависит от веба, скриптов и тестов.
3. Имена модулей не пересекаются со stdlib и пакетами из `requirements.txt` организаторов.
4. Сборка детерминирована и проверяется тестом: распаковка в пустой каталог и `python solution.py`.

## Варианты

### A. Плоские модули с префиксом `lex_`, в репозитории лежат в `src/`

Сборка копирует белый список `src/*.py` в корень ZIP. Импорты вида `import lex_settings`. В репозитории каталог `src/` — только раскладка, не пакет.

Плюс: совпадает с правилами платформы один в один, без склейки файлов. Минус: много файлов в корне архива.

### B. Пакет `lex/` плюс сборка в один файл

Разработка в пакете, перед сабмитом модули склеиваются. Риск: порядок, циклы, сломанные относительные импорты, тяжёлая отладка диффа склейки.

### C. Пакет внутри ZIP и `zipimport`

Платформа может не перенести не-`.py` файлы (нет `__init__.py` как каталога). Неизвестно, как устроен раннер. Отбрасываем.

## Решение

Вариант A.

- Префикс модулей ядра: `lex_`.
- Точка входа: `src/solution.py` → в архиве `solution.py`.
- Сборка: `scripts/build_archive.py`, белый список файлов, фиксированная дата в `ZipInfo`, сортировка имён.
- `sys.path` не трогаем в ядре. Точка входа импортирует соседей, потому что и в репозитории тесты запускают её из каталога, куда скопированы те же файлы.
- Направление зависимостей: `solution.py` → `lex_*` → ничего снаружи ядра. Проверяется тестом по импортам.

## Последствия

- Новый код ядра — новый `lex_<имя>.py` в `src/` и строка в манифесте сборки.
- Веб (`web/`) появляется позже и в ZIP не входит.
- PSB-3 добавит контейнерный прогон; этот ADR задаёт только раскладку и контракт архива.
